# v2.7.0 Executive Quality Cockpit — QA Document

## 1. Purpose

The Executive Quality Cockpit provides OEM leadership with a leadership-ready view of quality performance, risk, escalation, supplier issues, recurring defects, and cross-module quality signals. It is a deterministic, no-AI dashboard gated to Enterprise OEM users.

| Plan | Cockpit Access | What User Sees |

Backend enforcement: `requireFeature(session, "EXECUTIVE_COCKPIT")` in server-side data fetching. UI shows upgrade CTA for non-Enterprise.
