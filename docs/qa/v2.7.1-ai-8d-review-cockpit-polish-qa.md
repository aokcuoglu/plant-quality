## Malformed AI Provider Response Handling

This test requires simulating an AI response that does not match the expected schema.

### Scenario A: AI returns invalid JSON (not an object)

1. If possible, mock the AI provider to return a JSON array `[]` instead of an object
2. Click "Generate AI Review"
3. Verify the error message is shown: "AI returned an unexpected response format" or "Failed to parse AI 8D review response"
4. Verify the UI does not crash
5. Verify `isPending` resets to false (no stuck spinner)

### Scenario B: AI returns valid JSON missing required fields

1. If possible, mock the AI provider to return `{"overallScore": 80}` (missing reviewStatus, confidence)
2. Click "Generate AI Review"
3. Verify the review is saved to DB with defaults
4. After page refresh, verify `parseReviewResult` either returns a valid result or the "Review data could not be loaded" warning appears
5. Verify the "Regenerate Review" button is available

### Scenario C: AI timeout

1. If possible, set a very short AI_TIMEOUT_MS (e.g., 1ms) to force a timeout
2. Click "Generate AI Review"
3. Verify the error message: "AI request timed out. Please try again later."
4. Verify the UI does not crash and the spinner stops

### Scenario D: AI rate limit (HTTP 429)

1. If possible, mock or trigger a 429 response
2. Click "Generate AI Review"
3. Verify the error message: "AI service rate limit reached. Please wait a moment and try again."

## Remaining Risks

1. **AI model response variance:** The AI provider (DeepSeek or equivalent) may change response formats over time. The defensive parsing in `review-8d.ts` mitigates this, but novel malformation patterns could still cause `parseReviewResult` to return null. The malformed review warning state handles this gracefully.
2. **60-second timeout UX:** Long AI requests may cause users to navigate away. `startTransition` handles this correctly for React state, but the server-side action continues executing (no cancellation mechanism).
3. **Stored malformed data:** Any AI reviews saved with incorrect JSON before this fix will show the "Review data could not be loaded" warning and require regeneration. No automatic data repair is performed.
4. **No test automation:** There is no `npm test` script. All QA is manual.
