## 4. Score Calculation Explanation

Starting score: **100**

Penalties (each capped):

| Signal | Per-Item Penalty | Cap |
|--------|-----------------|-----|
| Open high/critical Field Defect | -10 | -30 |
| Repeat issue cluster | -15 | -30 |
| IQC rejected/on-hold/rework/sorting | -8 | -25 |
| Open/overdue 8D | -10 | -30 |
| SLA breach/escalation | -10 | -25 |
| PPAP approved with related issue history | -8 | -20 |
| FMEA coverage gap | -8 | -20 |
| Manual high-risk quality link or executive risk signal | -5 | -15 |

Final: clamp(0, 100 - totalPenalty)

Grades: A=90-100, B=75-89, C=60-74, D=40-59, E=0-39

Risk: Low=80-100, Medium=60-79, High=40-59, Critical=0-39
