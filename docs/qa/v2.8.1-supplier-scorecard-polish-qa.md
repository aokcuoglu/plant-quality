## 3. Score Accuracy Checks

- [ ] Enterprise OEM can navigate to `/quality/oem/scorecard`
- [ ] All scores are integers between 0 and 100
- [ ] No NaN, Infinity, or undefined values in score, grade, or risk level
- [ ] Empty data returns safe neutral state (score 100, grade A, risk low)
- [ ] Penalty caps are enforced: no single category exceeds its cap
- [ ] Total penalty = 100 - score (or 0 if score would be negative)
- [ ] `computeScore` returns 100 for totalPenalty that results in non-finite raw value
- [ ] `applyPenalty` returns 0 for NaN, Infinity, zero, or negative count values
- [ ] `getGrade` returns "E" for NaN or negative scores
- [ ] `getRiskLevel` returns "critical" for NaN or negative scores
- [ ] Grade mapping: A=90-100, B=75-89, C=60-74, D=40-59, E=0-39
- [ ] Risk mapping: Low=80-100, Medium=60-79, High=40-59, Critical=0-39
- [ ] Two runs with the same data produce identical scores

## 4. Sort Determinism

- [ ] Supplier ranking table is sorted by score ascending (worst first)
- [ ] Suppliers with equal scores are sorted by latestActivityAt descending
- [ ] Suppliers with equal scores and no activity are sorted by name ascending
- [ ] Sorting is reproducible across page reloads
