## 6. Status Workflow Checks

| Current Status | Valid Transitions | Actor |
|---------------|-------------------|-------|
| DRAFT | → OPEN, → CANCELLED | OEM |
| OPEN | → SUPPLIER_ACTION_REQUIRED, → CANCELLED | OEM |
| SUPPLIER_ACTION_REQUIRED | → OEM_REVIEW, → REVISION_REQUIRED, → CANCELLED | OEM |
| SUPPLIER_ACTION_REQUIRED | → OEM_REVIEW (submit for review) | Supplier |
| OEM_REVIEW | → COMPLETED, → REVISION_REQUIRED, → CANCELLED | OEM |
| REVISION_REQUIRED | → SUPPLIER_ACTION_REQUIRED, → CANCELLED | OEM |
| COMPLETED | (read-only) | — |
| CANCELLED | (read-only) | — |

- [ ] All transitions work correctly for OEM
- [ ] Supplier can only submit for review (SUPPLIER_ACTION_REQUIRED → OEM_REVIEW or REVISION_REQUIRED → OEM_REVIEW)
- [ ] Cannot transition from COMPLETED or CANCELLED
- [ ] Events are logged for each transition

## 7. Action Item Checks

| Action Status | Valid Transitions | Actor |
|---------------|-------------------|-------|
| OPEN | → IN_PROGRESS, → CANCELLED | OEM |
| IN_PROGRESS | → COMPLETED, → CANCELLED | OEM |
| OPEN (Supplier item) | → IN_PROGRESS | Supplier |
| IN_PROGRESS (Supplier item) | → SUBMITTED | Supplier |
| SUBMITTED | → ACCEPTED, → REJECTED | OEM |
| REJECTED | → IN_PROGRESS | Supplier |
| COMPLETED | (read-only) | — |
| CANCELLED | (read-only) | — |

- [ ] OEM can update all action items regardless of owner type
- [ ] Supplier can only update items with ownerType === "SUPPLIER"
- [ ] Supplier cannot access items with ownerType === "OEM"
- [ ] Overdue indicator shows on items past due date that are not completed/accepted/cancelled
