## 13. Changes in v2.9.1

### Bug Fixes

1. **Revalidation consistency:** OEM mutations (`updateDevPlanStatus`, `addActionItem`, `updateActionItem`, `addDevPlanComment`) now revalidate both OEM and supplier detail/list pages. `createDevPlan` with OPEN status also revalidates supplier list.

2. **COMPLETED/CANCELLED plan protection:** `updateActionItem` (OEM action) now rejects updates on COMPLETED/CANCELLED plans, matching the existing guard in `addActionItem`.

3. **Supplier action item protection:** `updateSupplierActionItem` now rejects updates when plan status is not SUPPLIER_ACTION_REQUIRED or REVISION_REQUIRED, and rejects updates to terminal-status action items (COMPLETED, ACCEPTED, CANCELLED).

4. **Overdue date comparison fix:** `isDevPlanOverdue()` and new `isActionItemOverdue()` use date-only comparison (start of day) instead of timestamp comparison, preventing plans/items due today from being incorrectly marked overdue.

5. **Supplier detail overdue badge:** Added overdue badge and red due date styling to supplier plan detail page.

6. **Supplier response form visibility:** Fixed `canActOnItems` / `canSubmit` distinction. Supplier can now see and interact with their action items when plan is in action-required state. Previously submitted responses are visible in read-only mode for non-action-required statuses.

7. **`getSupplierUsers` access hardening:** Now validates that the supplier is associated with the requesting OEM before returning user data.

8. **Client-side error handling:** All form actions (DevPlanActions, OemActionItemActions, AddActionItemForm, AddCommentForm, SupplierActionItemCard, SubmitForReviewButton) now display inline errors on failure and use `router.refresh()` instead of `window.location.reload()`.

9. **Button loading states:** All status transition and mutation buttons now show loading/disabled states during submission.

10. **Notification for COMPLETED/CANCELLED plans:** OEM `updateDevPlanStatus` now sends notifications to supplier users when plans are COMPLETED or CANCELLED.

11. **Scorecard CTA feature gating:** "Create Development Plan" link on scorecard detail page is now gated by SUPPLIER_DEVELOPMENT feature. Non-ENTERPRISE users see an upgrade message instead of the link.

### Known Limitations

- OEM "Move to Review" button from SUPPLIER_ACTION_REQUIRED allows OEM to skip supplier response. This is by design as an OEM override mechanism.
- No AI-generated action plans (deferred)
- No PDF/Excel export (deferred)
- No ERP integration (deferred)
- No automated supplier email digests (deferred)
