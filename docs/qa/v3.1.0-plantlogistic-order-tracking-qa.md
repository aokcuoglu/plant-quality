## 8. Status Workflow Checks

| From | To | Valid? |
|------|----|--------|
| DRAFT | SUBMITTED | Yes |
| SUBMITTED | COMMERCIAL_REVIEW | Yes |
| COMMERCIAL_REVIEW | APPROVED | Yes |
| COMMERCIAL_REVIEW | REJECTED | Yes |
| APPROVED | WAITING_PRODUCTION_PLAN | Yes |
| WAITING_PRODUCTION_PLAN | PLANNED | Yes |
| PLANNED | IN_PRODUCTION | Yes |
| IN_PRODUCTION | QUALITY_HOLD | Yes |
| IN_PRODUCTION | READY_FOR_DISPATCH | Yes |
| QUALITY_HOLD | IN_PRODUCTION | Yes |
| READY_FOR_DISPATCH | DISPATCHED | Yes |
| DISPATCHED | DELIVERED | Yes |
| DELIVERED | CLOSED | Yes |
| Any non-terminal | CANCELLED | Yes (OEM admin/authorized) |
| DRAFT | APPROVED | No (skips steps) |
| CLOSED | DRAFT | No (terminal) |
| CANCELLED | SUBMITTED | No (terminal) |

- [ ] All valid transitions succeed
- [ ] Invalid transitions are blocked with error message
- [ ] Status change creates timeline event with fromStatus and toStatus
- [ ] APPROVED status sets approvedAt timestamp
- [ ] REJECTED status sets rejectedAt timestamp
- [ ] DELIVERED status sets deliveredAt timestamp
- [ ] CLOSED status sets closedAt timestamp
