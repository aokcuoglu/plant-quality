- [ ] Dealer visiting `/logistic/portal/orders/[id]` for another dealer's order → 404 page (notFound), not raw error
- [ ] Distributor visiting `/logistic/portal/orders/[id]` for another distributor's order → 404 page (notFound)
- [ ] Dealer visiting `/logistic/portal/orders/[id]` for a distributor's order → 404 page (notFound)
- [ ] Dealer visiting `/logistic/portal/orders/[id]` for an order with `externalVisible=false` → 404 page
- [ ] Unauthenticated user visiting `/logistic/portal/*` → redirect to `/login`
- [ ] Supplier visiting `/logistic/portal` → redirect to `/quality/supplier` (via proxy)
- [ ] OEM user visiting `/logistic/portal` → redirect to `/logistic` (via proxy)
- [ ] Dealer visiting internal `/logistic/orders` → redirect to `/logistic/portal` (via proxy)
- [ ] No data existence leak: unauthorized order returns 404, not "access denied"
- [ ] No raw error pages shown to portal users
