## 3. SLA Calculation Rules

### 3.1 SLA Status Determination

| Condition | SLA Status |
|-----------|-----------|
| Order status DELIVERED or CLOSED | DELIVERED |
| Any milestone BLOCKED or QUALITY_HOLD, or yard blockedForDispatch, or order status QUALITY_HOLD | BLOCKED |
| Target date (requestedDeliveryDate or plannedDeliveryDate) past and not delivered | DELAYED |
| Target date within 7 days and not delivered | AT_RISK |
| No target date, no blocking issues | ON_TRACK |
| Dispatch ETA past and in transit | AT_RISK (via DELAYED path if target also past) |

### 3.2 Risk Level Determination

| Condition | Risk Level |
|-----------|-----------|
| DELIVERED | LOW |
| BLOCKED + target overdue | CRITICAL |
| BLOCKED (no target or target not overdue) | HIGH |
| DELAYED > 14 days overdue | CRITICAL |
| DELAYED 7-14 days overdue | HIGH |
| DELAYED 1-6 days overdue | MEDIUM |
| AT_RISK with quality hold | HIGH |
| AT_RISK without quality hold | MEDIUM |
| ON_TRACK | LOW |

### 3.3 Delay Category Logic

| Condition | Category |
|-----------|----------|
| BLOCKED + quality hold milestone | QUALITY_HOLD_AGING |
| BLOCKED + blocked milestone | PRODUCTION_DELAY |
| BLOCKED + yard blockedForDispatch | YARD_AGING |
| Milestone plannedFinish past and not completed | MILESTONE_OVERDUE |
| Dispatch plannedLoadingDate past and not LOADED | DISPATCH_DELAY |
| Dispatch ETA past and IN_TRANSIT | ETA_OVERDUE |
| Requested delivery date past | EXTERNAL_COMMITMENT_RISK |
| None of the above | DELIVERY_RISK or NONE |
