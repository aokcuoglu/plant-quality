# PlantX v3.5.1 — SLA + Delay Intelligence UX / Accuracy Polish — QA Checklist

**Version:** 3.5.1  
**Date:** 2026-05-23  
**Scope:** SLA/risk calculation accuracy, dashboard/list/detail consistency, external-safe visibility hardening, date/null/NaN handling, seed data clarity, lint cleanup

---

## 1. Purpose

Verify that v3.5.1 patch accurately polishes the SLA + Delay Intelligence module introduced in v3.5.0. Key focus areas:

- CANCELLED/REJECTED orders no longer appear as "Delivered" in SLA metrics
- Orders without target dates show "Not scheduled" instead of "Today" or misleading 0-day values
- Date calculations are DST-safe
- Invalid Date strings never render in the UI
- Badge styling is consistent across dashboard, order list, order detail, and delay-intelligence pages
- Portal pages do not expose internal delay data
- Supplier users cannot access logistic pages
